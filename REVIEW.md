# Review checklist

Everything that still needs a manual check before the data can be trusted. Links were found through web search results, which show **only the video title, not the channel that uploaded it**. Each link below was judged from its title, so "official" means "looks official", not "verified".

How to fix an entry: edit `js/data.js`, then change `official` / `live` (URL) and `officialType` / `liveType` (tag). Delete the URL to show a dash instead of a button.

## 3. Data and content written by Claude

- [ ] **Tracklists** came from the Forza fandom wiki, press releases and news coverage (Xbox Wire, NME, Gematsu, MSPowerUser and others). The FH2 list on one source flagged **Pixies – Debaser** and **The War on Drugs – Red Eyes** as missing in some version of the game; check whether they were removed.
- [ ] **FH5 Epitaph Records** was added in the **Series 19** update, not at launch.
- [ ] **Station taglines** and **genre chips** were written by Claude from the sources; adjust the wording if you like.
- [ ] **Hosts** shown: FH3 Epitaph (Keith Buckley), FH5 Epitaph (Chad Tepper), FH5 Horizon XS (Angélica Garcia). Others are left blank because no host was confirmed.
- [ ] **Game colors** are Claude's choice inspired by each setting, not official palettes: FH1 orange, FH2 violet, FH3 amber, FH4 green, FH5 magenta, FH6 crimson.
- [ ] **Sorting**: "The" counts when sorting, so "The Offspring" sorts under T. Change if you'd rather ignore it.
- [ ] **Station selection**: Innovative Leisure, Sub Pop, Ninja Tune, Horizon Pulse and Horizon Mixtape were left out on purpose (not rock/punk/metal). Vagrant Records leans alt-rock/pop-punk.
